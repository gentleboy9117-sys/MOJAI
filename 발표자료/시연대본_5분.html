시연 대본 — 5분 (클릭 단위)

시연 주소: steady-pudding-700503.netlify.app (백업: localhost:3000)
원칙: 말보다 화면이 먼저 움직인다 — 클릭하면서 말하기. 한 화면 30초 안팎, 스크롤은 천천히.

발표 30분 전 체크리스트

  • 시연 PC에서 라이브 주소 접속 확인 + 전 화면 한 번씩 열어 캐시 워밍
  • 브라우저 탭 5개 미리 열기: ① 대시보드 ② 이슈 모니터링 ③ 공안 모니터링 ④ 브리핑 ⑤ 보도자료 초안
  • 브라우저 확대율 110~125%(뒷자리 가독), 즐겨찾기바·확장프로그램 숨김
  • 알림·팝업 차단(윈도우 집중 지원), 와이파이+핫스팟 이중화
  • 백업 3종: 시연 영상 파일(오프라인) · PDF · 전체 화면 스크린샷 폴더
  • 당일 아침 자동수집 정상 반영 확인(대시보드 날짜·오늘 집회 수)
0:00탭① 대시보드

"방금 보신 화면들을, 지금 실제로 운영 중인 시스템에서 그대로 보여드리겠습니다. 지금 보시는 것은 오늘 아침 자동 수집된 실데이터입니다."

【상단 요약 카드 4개를 마우스로 훑기】

"출근 직후 이 한 화면입니다 — 오늘 공개 집회 몇 건, 관할 검찰청 몇 곳, 관련 보도까지 숫자로 바로 확인됩니다."

【이슈·공판·공안 TOP 5 영역으로 스크롤】

"이슈·공판·공안 각 영역의 TOP 5가 파급도 순으로 정리돼 있습니다." (~0:40)

0:40탭② 이슈 모니터링
【탭② 클릭 → 주요 이슈 Top 10】

"이슈 모니터링입니다. 밤사이 수백 건의 기사가 자동 수집·분류돼, 파급도 순 Top 10으로 정렬됩니다. 각 이슈에 관할 검찰청과 범죄유형이 자동으로 붙습니다."

【Top 1~2번 이슈의 파급도 숫자를 가리키며】

"이 파급도는 보도량·출처 수·확산 속도로 산정한 0~100 수치입니다. '감'이 아니라 숫자로 판단을 뒷받침합니다."

【이슈 하나의 제목 클릭 → 기사 원문 새 탭 → 바로 닫기】

"제목을 누르면 기사 원문으로 바로 이동합니다."

【기간 토글: 금일 → 금주 클릭 → 다시 금일】

"버튼 하나로 금일에서 금주 누적으로 — 지도·통계가 즉시 전환됩니다." (~1:40)

1:40전국 지도 + 검찰청별
【같은 화면에서 전국 지도로 스크롤】

"전국 검찰청별 이슈 분포입니다. 색이 진할수록 이슈가 많은 지역이고, 실제 검찰청 위치가 지도에 표시됩니다."

【상단 탭 '검찰청별 보기' 클릭】

"조직도에서 고검을 펼치면 산하 지검·지청까지 내려가고 —"

【검색창에 '성남' 입력】

"우리 청 이름만 검색하면, 전국 순위와 전일 대비 증감이 바로 나옵니다. 지청 단위 담당자에게 가장 요긴한 기능입니다." (~2:30)

2:30공판 모니터링
【좌측 메뉴 '공판 모니터링' 클릭】

"공판입니다. 법원 선고 보도만 정밀 선별해 주요 선고사건 Top 10으로 모읍니다 — 주요 선고를 놓쳐서 보고가 누락되는 일을 막아줍니다." (~2:50)

2:50탭③ 공안 모니터링
【탭③ 클릭 → 개요 잠깐 → '집회·시위 일정' 탭 클릭】

"공안입니다. 전국 지방경찰청 공개 게시판에서 집회 신고를 자동 수집하고, 집회 장소 기준으로 관할 검찰청을 자동 분류합니다."

【오늘/내일 버튼 클릭 한 번】

"오늘과 내일 일정을 날짜별·관할별로 봅니다."

【'노동·중대재해 보도' 탭 클릭】

"노동·중대재해, 집회·시위, 선거 보도는 분야별 전용 화면에서 조직도·순위로 집계됩니다." (~3:30)

3:30탭④ 브리핑★ 하이라이트 — 절대 사수
【탭④ 클릭 → 기간·검찰청·범죄유형 드롭다운 선택】

"이제 산출물입니다. 기간, 검찰청, 범죄유형 — 조건만 고르고,"

【'브리핑 생성' 클릭】

"클릭 두 번이면… 보고용 1페이지 브리핑 초안이 완성됩니다."

【결과를 위→아래로 천천히 스크롤】

"핵심 이슈 TOP 5, 주요 검찰청, 유형 통계가 표준 목차로 정리되고, 파일로 바로 다운로드됩니다. 매일 아침 보고 초안이 이렇게 나옵니다." (~4:10)

4:10탭⑤ 보도자료 · 문자풀
【탭⑤ 클릭 → '샘플 입력 불러오기' 클릭】

"보도자료 초안입니다. 발표기관·담당부서·죄명·처분 — 기초 정보만 입력하면,"

【'생성' 클릭 → 결과 상단만 보여주기】

"실제 배포 양식 그대로 — 유의문구, 공보관 연락처, 공개요건, 목차까지 자동 구성됩니다. 사실관계는 입력값만 사용하고, 없는 내용은 지어내지 않습니다."

【좌측 메뉴 '문자풀 초안' 클릭, 화면만 잠깐】

"기자단 문자풀도 같은 방식입니다 — 서술식·개조식 전환까지 지원합니다." (~4:50)

4:50탭① 복귀 · 마무리

"수집부터 산출물까지 하나의 흐름 — 방금 보신 전부가 지금 이 순간에도 자동으로 돌아가고 있습니다. 이상 시연을 마치고 질문 받겠습니다. 감사합니다." (5:00)

돌발 대응

상황대응
페이지 로딩 지연"라이브 서비스라 잠시 지연될 수 있습니다" → 새로고침 1회 → 안 되면 다음 화면 진행, 말미 재시도
인터넷 단절핫스팟 전환(30초) → localhost:3000 → 그것도 안 되면 시연 영상 재생으로 전환
생성 지연(브리핑·보도자료)"생성되는 동안 설명드리면 —" 하고 기능 설명 이어가기(무음 공백 금지)
원문 링크가 이상한 기사로 연결바로 탭 닫고 "원문 연결 기능입니다" 한 줄로 통과(재클릭 금지)
예상 못 한 데이터 표시그 자리 수정 시도 절대 금지 — "실데이터 특성입니다" 후 진행

남을 때 추가: 키워드 통합검색 1회('성남' 검색 → 제목·내용·검찰청 통합 결과), 제도/정책 이슈 탭 한 컷
